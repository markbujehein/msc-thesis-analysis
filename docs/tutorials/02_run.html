Write interval4 steps = 2 fsThe highest energy you can see is h/(2 × 2 fs) = about 1030 meV, above the O–H stretch (about 460 meV in GAFF2).

import numpy as np
import openmm as mm
import openmm.app as app
from run import VelocityReporter

def tiny_simulation():
    system = mm.System()
    for _ in range(2): system.addParticle(12.0)
    bond = mm.HarmonicBondForce(); bond.addBond(0, 1, 0.15, 1e5); system.addForce(bond)
    top = app.Topology(); res = top.addResidue("X", top.addChain())
    for name in ("C1", "C2"): top.addAtom(name, app.Element.getBySymbol("C"), res)
    sim = app.Simulation(top, system, mm.VerletIntegrator(0.0005))   # 0.5 fs, in ps
    sim.context.setPositions([[0, 0, 0], [0.16, 0, 0]])
    sim.context.setVelocitiesToTemperature(10)
    return sim

def test_the_reporter_writes_every_4th_step(tmp_path):
    sim = tiny_simulation(); out = tmp_path / "v.npy"
    reporter = VelocityReporter(out, every=4)
    sim.reporters.append(reporter); sim.step(40); reporter.close()
    assert np.load(out).shape == (10, 2, 3)

OpenMM's built-in DCDReporter saves positions only. Write a small reporter class with describeNextReport and report, following the pattern in the OpenMM documentation ("Extracting and Reporting Forces"). Ask for 'velocities', collect state.getVelocities(asNumpy=True) as float32, and write the array in close().

The documentation shows describeNextReport returning a dictionary with steps and include keys. Older OpenMM versions used a tuple. This test will tell you which your version accepts.
