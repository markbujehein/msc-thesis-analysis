1 Build the system

Goal: md/build.py with three functions, tested, and md/01_system.py showing the checks. Run pixi run -e md pytest from md/, so build is importable. Put the tests in md/tests/test_build.py.

The cell is the 2×2×1 PDB (1800 atoms, 72 molecules). The unit cell is too narrow for a 1 nm cutoff.

read_pdb(path) returns the atoms (name, element, residue number, position) and the box from the CRYST1 line. A PDB uses fixed columns: atom name 13–16, residue number 23–26, x, y, z in 31–38, 39–46, 47–54, element 77–78.

Find the bonds

Write this test first. It must fail.
from build import bonds_from_geometry

def test_every_molecule_has_25_bonds():
    atoms, box = read_pdb(PDB)
    bonds = bonds_from_geometry(atoms)
    per_molecule = {}
    for i, j in bonds:
        per_molecule[atoms[i].residue] = per_molecule.get(atoms[i].residue, 0) + 1
    assert set(per_molecule.values()) == {25}
Then write the least code that passes.

Two atoms are bonded when they are closer than 1.2 Å if one is hydrogen, 1.7 Å otherwise. Molecules in this PDB are whole, so you need no periodic wrapping. The bond count of 25 is 11 heavy-atom bonds plus 14 bonds to hydrogen.

Why geometry?The PDB has no bond records, and OpenMM cannot guess bonds for a residue it does not know. Without bonds the parameter generator cannot match the molecule.

Then write the least code that passes.

Use openmmforcefields' SystemGenerator with small_molecule_forcefield="gaff-2.11", the thymol molecule from Molecule.from_smiles, and forcefield_kwargs={"constraints": None, "rigidWater": False}. Particle mesh Ewald and the cutoff go in through the generator's periodic settings: check its documentation for the exact argument name before you write it.

Do not copy two lines from the openmmforcefields example: constraints: HBonds and hydrogenMass: 4 * unit.amu. They make production runs faster and they also change the hydrogen vibrations, which is the spectrum you are after.

Set the box vectors from read_pdb: the hexagonal cell is triclinic.

Minimise and check the energy

Write this test first. It must fail.
import math
import openmm as mm
import openmm.unit as u
import openmm.app as app

def test_energy_is_finite_after_minimisation():
    system, topology, positions = make_system(PDB, THYMOL, cutoff_nm=1.0)
    sim = app.Simulation(topology, system, mm.VerletIntegrator(0.0005))
    sim.context.setPositions(positions)
    sim.minimizeEnergy()
    energy = sim.context.getState(getEnergy=True).getPotentialEnergy()
    assert math.isfinite(energy.value_in_unit(u.kilojoule_per_mole))
Then write the least code that passes.

A failure here is informative: an energy of nan usually means overlapping atoms or a wrong box. Check the box before the force field.

Cells for md/01_system.py, each calling the module and showing the result:

  • atom, molecule and bond counts, and the box lengths in Å;
  • the number of constraints (it must be 0);
  • the energy after minimisation, in kJ/mol;
  • the O–H bond of the GAFF2 system: its force constant k and the harmonic energy ħ√(k/μ), with μ = mOmH/(mO+mH), in meV.
