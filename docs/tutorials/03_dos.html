3 Compute the DOS

Goal: md/dos.py turning velocities into g(E) with energy in meV, and md/03_dos.py showing it. This step needs only numpy, so it works before the full environment is installed. Tests go in md/tests/test_dos.py.

The idea

The power spectrum of the velocities is the Fourier transform of their autocorrelation function. Its peaks sit at the vibrational energies. Energy follows from frequency as E = h·f, with h = 4135.667696 meV·fs. The resolution of a run of N frames spaced dt apart is h/(N·dt).

One oscillator, one peak

Write this test first. It must fail.
import numpy as np
from dos import dos, resolution_mev

H_MEV_FS = 4135.667696          # Planck constant in meV*fs

def oscillator(energy_mev, n=20000, dt_fs=2.0, atoms=3):
    t = np.arange(n) * dt_fs
    f = energy_mev / H_MEV_FS   # 1/fs
    phase = np.random.default_rng(0).uniform(0, 2 * np.pi, (1, atoms, 3))
    return np.cos(2 * np.pi * f * t[:, None, None] + phase)

def test_peak_is_at_the_oscillator_energy():
    e, g = dos(oscillator(41.0), dt_fs=2.0)
    assert abs(e[np.argmax(g)] - 41.0) < 2 * resolution_mev(20000, 2.0)

def test_resolution_is_h_over_total_time():
    assert abs(resolution_mev(20000, 2.0) - H_MEV_FS / (20000 * 2.0)) < 1e-9

def test_two_oscillators_give_two_peaks():
    v = oscillator(41.0)[:, :2] + 0 ; w = oscillator(120.0)[:, :2]
    e, g = dos(np.concatenate([v, w], axis=1), dt_fs=2.0)
    top = e[np.argsort(g)[-40:]]
    assert (abs(top - 41.0) < 1).any() and (abs(top - 120.0) < 1).any()

import numpy as np

H_MEV_FS = 4135.667696          # Planck constant in meV*fs

def resolution_mev(n_frames, dt_fs):
    return H_MEV_FS / (n_frames * dt_fs)

def dos(velocities, dt_fs):
    """velocities: (n_frames, n_atoms, 3). Returns energy in meV and g(E) normalised to area 1."""
    n = len(velocities)
    x = velocities.reshape(n, -1)
    x = (x - x.mean(0)) * np.hanning(n)[:, None]        # remove drift, taper the ends
    g = (np.abs(np.fft.rfft(x, axis=0)) ** 2).sum(1)     # power spectrum = Fourier transform of the VACF
    e = np.fft.rfftfreq(n, d=dt_fs) * H_MEV_FS
    return e, g / np.trapezoid(g, e)

h_projected_dos(velocities, dt_fs, is_hydrogen) selects the hydrogen atoms and calls the same function. In the incoherent approximation the neutron signal is dominated by hydrogen, so this is the curve to compare with TOSCA.
